# Evidencia 02: Ciclo completo Crear (POST), Consultar (GET), Reprogramar (PATCH) y Cancelar (DELETE) con verificación en SQLite
Fecha y hora: 2026-10-22T20:27:16-05:00
Qué se probaba: Crear una reserva nueva en FastAPI (201), consultarla por su código VF-..., reprogramarla a una nueva hora (200) verificando historial_reprogramaciones, y cancelarla con confirmado=true (200), comprobando tras cada paso el estado real de la fila en SQLite.
Comandos ejecutados:
  curl -sS -i -X POST http://127.0.0.1:8012/citas -H 'Content-Type: application/json' -d '{"cliente":"Paciente Evidencia 02","servicio":"deportiva","fecha":"2026-10-28","hora":"08:00","fisioterapeuta":"mariana","confirmado":true}'
  curl -sS -i http://127.0.0.1:8012/citas/<CODIGO>
  curl -sS -i -X PATCH http://127.0.0.1:8012/citas/<CODIGO>/reprogramar -H 'Content-Type: application/json' -d '{"nueva_fecha":"2026-10-28","nueva_hora":"10:30","confirmado":true}'
  curl -sS -i -X DELETE 'http://127.0.0.1:8012/citas/<CODIGO>?confirmado=true'
  python -c "import sqlite3, json; ... SELECT * FROM reservas WHERE codigo=<CODIGO>"
